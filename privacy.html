Privacy policy

Last updated: November 20, 2026

Personal gog CLI is a single-user tool. Its only user is the owner of the Google account it connects to.

Data accessed

With the owner's consent, the tool uses Google's Gmail API with two permissions: read-only access to mail, and permission to create and manage drafts.

How data is used

Mail is read on the owner's own computer, at the owner's request, to search, summarize and draft replies. The owner may pass content to an AI assistant they use for that purpose. The tool does not send mail.

Storage and sharing

The access token is stored in the owner's operating-system keychain. The tool keeps no server-side copy of any mail. No data is sold, used for advertising, or shared with anyone other than the owner.

Revoking access

Access can be removed at any time from the Google Account's security settings, under third-party connections.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
